# ラブカ デッキビルダー Android版

ラブライブ！シリーズ オフィシャルカードゲーム用の、スマホ向けデッキ作成アプリです。

## 主な機能

- カード名・カード番号・作品名・商品名で検索
- メンバー / ライブ / エネルギーで絞り込み
- メインデッキとエネルギーデッキを個別管理
- メイン同一カード番号4枚上限チェック
- 60枚（メンバー48 + ライブ12）+ エネルギー12枚の枚数チェック
- デッキをJSONで共有 / 取込
- 公式カードリストをブラウザで確認
- JSONカードDB一括取込（2,500件以上でも利用できる構成）
- カードを手動追加
- GitHub ActionsだけでAPKを自動ビルド

## 重要

同梱の `cards.json` は動作確認用の小規模な初期データです。
公式カード全件の画像・本文をこのリポジトリへ無断複製する構成にはしていません。
アプリ内の「カードDB取込」から、自分で用意したJSONを一括取込できます。

JSON形式:

```json
[
  {
    "id": "カード番号",
    "name": "カード名",
    "type": "メンバー",
    "work": "作品名",
    "set": "収録商品"
  }
]
```

`type` は `メンバー` / `ライブ` / `エネルギー` のいずれかを推奨します。

## スマホだけでGitHubへアップロード

1. このZIPをスマホへ保存
2. ファイルアプリでZIPを展開
3. GitHubで `lovelive-deck-builder` リポジトリを開く
4. `Add file` → `Upload files`
5. 展開したプロジェクト内のファイルとフォルダをアップロード
6. Commit changes

GitHubのモバイル表示でフォルダ一括アップロードが難しい場合は、Chromeの「PC版サイト」を有効にすると操作しやすくなります。

## APKを作る

アップロードすると自動ビルドが走ります。手動実行もできます。

1. GitHubリポジトリ → `Actions`
2. `Build Android APK`
3. `Run workflow`
4. ビルド完了後、実行結果を開く
5. `Artifacts` の `lovelive-deck-builder-apk` をダウンロード
6. ZIPを展開して `app-debug.apk` をAndroidへインストール

## デッキ枚数

公式大会で案内されている一般的な構成に合わせ、メイン60枚
（メンバーカード48枚 + ライブカード12枚）とエネルギーデッキ12枚を検証します。
ポイントシステム等の最新制限は公式サイトで必ず確認してください。

## 公式サイト

アプリの「公式カードリスト」ボタンから公式カードリストを開けます。
